
# Jenkins Pipeline Demo

This repository demonstrates a declarative Jenkins pipeline.

## Pipeline Stages

1. Checkout - Prepare the source workspace.
2. Build - Generate a sample build artifact.
3. Test - Verify the generated artifact.
4. Deploy - Demonstrate a deployment stage.

## Technologies

- Git
- GitHub
- Jenkins
- Declarative Pipeline

## Objective

To demonstrate automated CI pipeline execution
using a Jenkinsfile stored in GitHub.
